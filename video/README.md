# AAM year-wrap videos

A personalised end-of-year video for each student, built from their two
**All About Me** surveys (AAM1 at the start of the year, AAM2 at the end).

```
schools/{id}/surveys/AAM1-*, AAM2-*  ──►  buildStoryline()  ──►  storyline JSON  ──►  Remotion  ──►  MP4
          (+ responses/{studentId})        src/storyline/        (reviewable,         src/remotion/
                                                                  editable)
```

- **Segments**: `prep` (AAM1-prep / AAM2-prep) and `mid` (AAM1-mid / AAM2-mid).
  Each segment has its own theme: colours, font and music.
- **Storyline**: plain JSON listing the scenes. It's the only input the
  renderer needs, so an edited storyline re-renders without re-reading the
  surveys.
- **Missing answers** degrade step by step. Both rounds give an "evolved" or
  "stayed" scene, one round gives a single statement, and neither gives a
  generic line (dream) or drops the scene. Each degradation is listed in
  `storyline.warnings`.

## Commands

```bash
npm install
npm test                    # storyline engine tests (node --test)
npm run studio              # Remotion Studio: live preview with the sample props
npm run render:samples      # renders fixtures/sample-students.mjs → out/*.mp4
npm run music               # regenerates public/music/*.mp3 (numpy + ffmpeg)
```

In the cloud sandbox, point Remotion at the preinstalled Chromium:
`REMOTION_BROWSER=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`.

Rendering needs an emoji font on the machine (`fonts-noto-color-emoji` on
Debian/Ubuntu). Without one, the answer emojis render as boxes.

## Files

| Path | What |
|---|---|
| `src/storyline/questions.mjs` | Which AAM question plays which role, matched by id and then by text |
| `src/storyline/copy.mjs` | Every line the video says, with per-student variants |
| `src/storyline/buildStoryline.mjs` | Answers → scenes, with fallbacks and warnings |
| `src/remotion/` | The template: theme per segment, 10 scene types |
| `fixtures/aam-surveys.json` | Real AAM question/option definitions (English only, no student data) |
| `fixtures/sample-students.mjs` | Fictional students used for tests and sample renders |
| `public/music/` | Original background tracks generated by `scripts/make-music.py`, no licence needed |
